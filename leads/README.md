# Leads

## test-subscribers.csv

**These are synthetic people, not real customers.**

- Every address uses `example.com`. That domain is reserved for testing and can never reach a real inbox.
- There's one profile for each welcome-series version (A to E), plus edge cases: no first name, no stage, already ordered.
- Use these only with a Mailtrap **Email Testing** (sandbox) inbox, which catches every email and delivers none.

Never add real customer data to this folder, and never connect it to a real customer database.
