# Leads folder rules

These rules apply to everything in `leads/`, on top of the studio rules in the main CLAUDE.md.

1. **Everyone here is made up.** The people in these files are practice leads, not real customers.
2. **Never add real people or real email addresses.** Don't copy in names, emails or details of anyone real, even as a test.
3. **Every row needs a consent value.** Don't add a row with an empty `consent` column, and don't guess one.
4. **Never change the `@example.com` addresses.** That domain is reserved and can never receive email, which is what keeps real people from being emailed. Don't edit these addresses or swap them for another domain.
